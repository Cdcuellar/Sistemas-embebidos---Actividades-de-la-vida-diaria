dec_a_bcd

Convierte un valor decimal (0-99) a formato Binary Coded Decimal (BCD).

Convierte un valor decimal (0-99) a formato Binary Coded Decimal (BCD)El chip RTC DS3231 almacena fecha/hora en BCD: cada dígito decimal se codifica en 4 bits (nibble). Por ejemplo, 42 decimal → 0x42 BCD (4 en bits [7:4], 2 en bits [3:0]).

Parameters
valValor decimal en rango [0, 99]
Returns
Byte en formato BCD (dos dígitos decimales empaquetados)

(59) → (5 << 4) | 9 = 0x59
